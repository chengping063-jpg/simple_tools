# 七星剑 CNVD 测试工具

七星剑 CNVD 是一个基于 Tkinter 的 Windows 桌面工具，用于在授权范围内进行资产采集、资产整理、存活检测和简单的 Payload 探测。当前仓库包含测试版本主程序：

```text
七星剑CNVD_1.2_测试版本.pyw
```

## 功能概览

- FOFA 采集：支持单条 FOFA 查询语法拉取资产，也支持从 TXT 批量读取指纹语法并发查询。
- 指纹批量查询：可配置 FOFA Key、查询数量、淘汰阈值和并发线程数；支持指纹 TXT 与资产 TXT 交叉探测。
- 资产表格管理：表格字段包括国家、备案、标题、资产链接、响应长度、状态码和指纹信息。
- 资产导入导出：支持从 TXT/CSV 导入资产，支持将表格资产导出为带时间戳的 TXT 文件。
- 存活检测：对勾选资产进行并发 HTTP 测活，可配置线程数、超时时间和允许的状态码。
- 任务控制：测活支持暂停、继续和停止；FOFA 批量任务支持当前资产完成后优雅停止。
- Payload 探测：支持拼接 URI、GET/POST 请求、Token 提取拼接和 CORS 跨域检查。
- 文本清洗：支持主/副文本自去重、交叉去重、尾部特征截断清洗，以及表格 URL 逗号拼接复制。
- Burp Suite 启动：可配置 Burp Suite 启动文件，左键启动、右键重设路径。
- 本地配置保存：FOFA 参数、路径、线程数、Payload 参数等会保存到本地 `config.json`。
- 授权绑定：首次运行会根据机器码要求输入激活密钥，通过后保存到本地配置。

## 环境要求

- Windows 系统
- Python 3.10 或兼容版本
- Tkinter，通常随 Windows 版 Python 一起安装
- FOFA API Key，仅 FOFA 采集功能需要

必需依赖：

```powershell
python -m pip install requests urllib3
```

可选依赖：

```powershell
python -m pip install psutil tkinterdnd2
```

说明：

- `psutil` 用于显示 CPU/RAM 状态，缺失时程序仍可运行。
- `tkinterdnd2` 用于拖拽导入 TXT/CSV/目录/WAV，缺失时仍可通过浏览按钮选择文件。
- `winsound` 是 Windows 内置模块，用于任务完成提示音。

## 运行方式

在项目目录中执行：

```powershell
python ".\七星剑CNVD_1.2_测试版本.pyw"
```

也可以在 Windows 资源管理器中双击 `.pyw` 文件启动。

首次启动时，程序会显示本机机器码并要求输入激活密钥。验证成功后会进入主界面，并将授权信息保存到 `config.json`。

## 基本使用流程

1. 启动程序并完成设备授权。
2. 在“FOFA 采集”页填写 FOFA Key、查询语法和获取数量，执行单条查询；或选择指纹 TXT 执行批量查询。
3. 在“资产管理与测活”页粘贴、导入或整理资产，勾选目标后配置并发、超时和状态码。
4. 执行测活，程序会保留匹配状态码的资产并剔除失效资产。
5. 需要进一步探测时，在“自动化 Payload”页配置 URI、POST 数据、Token 规则或 CORS 检查后运行。
6. 使用“文本去重清洗”页对资产文本做去重、交叉比对和 URL 批量提取。
7. 点击“一键导出”保存表格中的资产结果。

## 输入与输出

程序可能在本地生成或读取以下文件：

- `config.json`：保存授权信息、FOFA Key、路径、线程数、Payload 参数等本地配置。
- `FOFA_自动分拣结果/`：未指定导出目录时，批量 FOFA 查询会自动创建该目录保存结果。
- `资产导出_YYYYMMDD_HHMMSS.txt`：一键导出或自动保存时生成的资产列表。
- 用户选择的 TXT/CSV 文件：用于资产导入、指纹批量查询和文本去重。

## 安全与合规说明

本工具包含资产采集、存活检测和 Payload 请求能力，仅应在明确授权的测试环境或授权资产范围内使用。源码中部分网络请求使用 `verify=False` 关闭 TLS 证书校验，用于兼容复杂测试环境；在生产网络或敏感环境中使用前，应评估由此带来的安全风险。
